# Community conduct

Raag Studio welcomes people with different musical tastes, technical backgrounds and levels of experience.
Help make the project a place where people can ask clear questions, share work and learn.

- Give specific, constructive feedback about the work. Critique an implementation or musical choice without
  insulting the person behind it.
- Respect differences in language, culture, identity, ability and experience.
- Ask before sharing another person's private messages, recordings, lyrics or identifying information.
- Keep issues and pull requests relevant, and assume good faith while checking claims against evidence.
- Harassment, threats, discriminatory abuse, impersonation, spam and deliberate privacy violations are unwelcome.

Maintainers may edit or hide harmful content, close disruptive threads and restrict participation when needed.
GitHub's Report content/Report abuse tools are available for platform violations. Security vulnerabilities should
follow [SECURITY.md](SECURITY.md), with details kept out of public issue threads.

These expectations apply in the project's issues, pull requests, discussions and reviews.
