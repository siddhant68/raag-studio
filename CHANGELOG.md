# Changelog

## 0.3.0-alpha.1 — 2026-10-25

First clean open-source application release, derived from the working Raag Studio development snapshot.

- Local brief-to-music app with editable plans, song maps, library, favourites, refinement and export.
- Thirty-eight style presets, fifty-six instruments and optional Claude planning/songwriting.
- Guarded sequential ACE-Step generation with explicit profiles and retained request/result provenance.
- Twelve real showcase performances and independent technical measurements.
- Musical pipeline preserved; runtime-path configuration made portable for fresh clones.
- Pinned app/engine setup, configuration docs, contribution/security guidance and automated CI.

Real generation is validated on Apple Silicon macOS. This is an early-access release; human musical ratings
and broader hardware validation remain open.
