# Roadmap

This is a direction for contributions, not a promise of delivery dates.

## First public release

- A clear brief → plan → performance workflow and local library.
- Thirty-eight style presets, fifty-six instruments, exact-lyric handling and genre-aware song maps.
- Optional smart planning/songwriting and explicit engine profiles.
- A pinned Apple Silicon engine setup, reproducible requests and real listening examples.

## Next useful work

- Validate installation and memory behaviour across more Apple Silicon Macs.
- Improve Hindi/English sung-word evaluation with human listening evidence.
- Evaluate duet handoffs, rap/sung contrast and arrangement adherence by style.
- Improve onboarding, accessibility and recovery messages.
- Add measured comparisons for LM/XL and shift settings without claiming a universal best profile.
- Explore additional platforms/engines behind the same request and capability boundaries.

Score editing, stems, MIDI, melody-preserving repair and multi-user hosting need separate design and validation.
